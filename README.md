# 📚 বইঘর — বাংলা অনলাইন বইয়ের দোকান

একক বিক্রেতার জন্য সম্পূর্ণ ই-কমার্স ওয়েবসাইট।
**Next.js 16 + Supabase + Vercel** — সবই ফ্রি টিয়ারে চলে।

ক্যাশ অন ডেলিভারি, bKash/Nagad ম্যানুয়াল পেমেন্ট, বাংলা ইন্টারফেস,
গেস্ট চেকআউট (ক্রেতাকে অ্যাকাউন্ট খুলতে হয় না)।

### স্বয়ংক্রিয় কাজ (Cron) ✅

প্রতিদিন একবার (সকাল ৯টা বাংলাদেশ সময়) `/api/cron/courier-sync` চলে —
পাঠানো অর্ডারগুলোর স্টেটাস কুরিয়ার থেকে টেনে আনে। ডেলিভারি হলে অর্ডার
নিজে থেকেই "ডেলিভারি সম্পন্ন" হয়, আর COD হলে পেমেন্টও "পরিশোধিত"।

> ⚠️ **Vercel Hobby plan এ দিনে একবারের বেশি চলে না** — এর বেশি চাইলে
> ডিপ্লয়ই ফেল করবে। এর চেয়ে ঘন ঘন সিঙ্ক দরকার হলে বাইরের ফ্রি ক্রন সার্ভিস
> (যেমন cron-job.org) দিয়ে একই এন্ডপয়েন্টে হেডার সহ কল করুন —
> বিস্তারিত [`supabase/README.md`](supabase/README.md) §৭।

### নিরাপত্তা ✅

- তিন স্তরের সুরক্ষা: Proxy → Admin Layout → PostgreSQL RLS
- অর্ডারের দাম/স্টক/ডিসকাউন্ট **সবসময় সার্ভারে** হিসাব হয়
- কুপন কোড কখনো ব্রাউজারে পড়া যায় না
- স্টক লকিং সহ ট্রানজ্যাকশনাল অর্ডার তৈরি
- রিভিউ অ্যাপ্রুভ না করে সাইটে আসে না
- **রেট লিমিট** — একই ফোন থেকে ১০ মিনিটে ৩টি, দিনে ১০টির বেশি অর্ডার নয়
  (অ্যাপ + ডেটাবেস ট্রিগার, দুই স্তরে)
- Cron এন্ডপয়েন্ট `CRON_SECRET` ছাড়া কেউ কল করতে পারে না

## দ্রুত শুরু (৫ ধাপ)

### ১. ডিপেন্ডেন্সি

```bash
npm install
```

### ২. Supabase প্রজেক্ট ও ডেটাবেস

[`supabase/README.md`](supabase/README.md) অনুসরণ করুন। সংক্ষেপে:

1. supabase.com এ নতুন প্রজেক্ট (Region: **Singapore**)
2. **API Keys** থেকে URL + Publishable + Secret কী নিন
3. **SQL Editor** এ ৭টি migration ফাইল **ক্রম অনুযায়ী** চালান
4. `public.staff` এ নিজের অ্যাকাউন্ট যোগ করুন (নাহলে অ্যাডমিনে ঢুকতে পারবেন না)
5. চাইলে কুরিয়ার সংযুক্ত করুন — [`supabase/README.md`](supabase/README.md) §৭

### ৩. পরিবেশ ভেরিয়েবল

```bash
cp .env.example .env.local
```

তারপর `.env.local` খুলে আসল মান বসান:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxx
SUPABASE_SECRET_KEY=sb_secret_xxx
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_STORE_NAME=বইঘর

# ঐচ্ছিক — না দিলেও সাইট পুরো চলবে (কুরিয়ার ইন্টিগ্রেশন বন্ধ থাকবে)
STEADFAST_API_KEY=
STEADFAST_SECRET_KEY=
CRON_SECRET=
```

> **যেগুলো না দিলেও চলে:** `STEADFAST_*` (কুরিয়ার অটো-বুকিং বন্ধ থাকবে,
> কিন্তু CSV এক্সপোর্ট ও হাতে ট্র্যাকিং কোড লেখা কাজ করবে) এবং
> `CRON_SECRET` (তখন স্বয়ংক্রিয় স্টেটাস সিঙ্ক চলবে না)।
> প্রথম চারটি **অবশ্যই লাগবে**।

### ৪. চালান

```bash
npm run dev
```

- ওয়েবসাইট → http://localhost:3000
- অ্যাডমিন → http://localhost:3000/login

> ডেমো বই ৫টি সিড করা আছে (`demo-pather-panchali` ইত্যাদি)।
> মুছতে: `delete from public.books where slug like 'demo-%';`

### ৫. Vercel এ ডিপ্লয়

1. কোড GitHub এ পুশ করুন
2. [vercel.com/new](https://vercel.com/new) → রিপোজিটরি ইমপোর্ট
3. **Environment Variables** এ চারটি মান বসান (ধাপ ৩ এর মতো, তবে
   `NEXT_PUBLIC_SITE_URL` = আপনার আসল ডোমেইন)
4. **Deploy** চাপুন

`vercel.json` এ Region `sin1` (Singapore) দেওয়া আছে — বাংলাদেশের জন্য
সবচেয়ে কম লেটেন্সি। ফ্রেমওয়ার্ক Next.js স্বয়ংক্রিয়ভাবে শনাক্ত হবে।

> ⚠️ **প্রথম ডিপ্লয়ের আগেই env ভেরিয়েবল বসান।** একটিও না থাকলে বিল্ড
> স্পষ্ট এরর দেবে: `পরিবেশ ভেরিয়েবল "NEXT_PUBLIC_SUPABASE_URL" পাওয়া যায়নি`।

## কমান্ড

```bash
npm run dev          # ডেভেলপমেন্ট সার্ভার (http://localhost:3000)
npm run build        # প্রোডাকশন বিল্ড
npm start            # বিল্ড করা অ্যাপ চালান
npm run test         # ইউনিট টেস্ট (৯২টি, ~২ সেকেন্ডে)
npm run typecheck    # শুধু টাইপ চেক (দ্রুত)
npm run check        # typecheck + test + build — কমিটের আগে এটাই চালান
npm run db:types     # ডেটাবেস থেকে টাইপ অটো-জেনারেট (supabase CLI লাগে)
```

> **কিছু বদলালে কমিট করার আগে `npm run check` চালান।** এক কমান্ডে তিনটি
> যাচাই হয়ে যাবে — টাইপ ভুল, টেস্ট ফেল, বিল্ড ভাঙা। CI-ও এটাই চালায়।

## জানার মতো বিষয়

### Supabase Free plan

৫০০ MB ডেটাবেস · ১ GB ফাইল স্টোরেজ · ৫ GB/মাস ব্যান্ডউইথ · ২টি প্রজেক্ট।
**৭ দিন কোনো ট্রাফিক না থাকলে প্রজেক্ট পজ হয়ে যায়** — তখন Dashboard
থেকে "Restore" চাপতে হয়। ডেলিভারি শুরু হলে এই সমস্যা আর হবে না।

### দৈনিক কাজ

1. নতুন অর্ডার দেখুন → **Admin → Orders → নতুন** ট্যাব
2. কাস্টমারকে কল করে নিশ্চিত করুন → স্টেটাস **নিশ্চিত হয়েছে**
3. bKash পেমেন্ট হলে **পেমেন্ট** কার্ডে TrxID মিলিয়ে **পরিশোধিত** মার্ক করুন
4. বই প্যাক করে পাঠান — দুই উপায়ে:
   - **কুরিয়ার সংযুক্ত থাকলে:** অর্ডার খুলে **"কুরিয়ারে বুক করুন"** চাপুন
     → ট্র্যাকিং কোড নিজে থেকেই বসবে, স্টেটাস **পাঠানো হয়েছে** হবে
   - **সংযুক্ত না থাকলে:** **"কুরিয়ারের জন্য CSV"** ডাউনলোড করে
     কুরিয়ারের পোর্টালে পেস্ট করুন, তারপর ট্র্যাকিং কোড হাতে লিখুন
5. এরপর নিজে থেকে হয়ে যাবে — প্রতিদিন একবার Cron স্টেটাস দেখে
   **ডেলিভারি সম্পন্ন** করে দেবে (COD হলে পেমেন্টও "পরিশোধিত")

### বাতিল করলে স্টক ফেরত

অর্ডার **বাতিল** বা **ফেরত এসেছে** করলে বইয়ের স্টক স্বয়ংক্রিয়ভাবে ফিরে
যোগ হয় — একবারই (ডাবল ফেরত হবে না)।
